# Stall Booking

Stall Booking is a small private web app used by the organizers of the "Be Pakistani, Buy Pakistani" expo (PROWESS) to keep accurate records of stall bookings.

**What it does**
- Organizers paste a stall booking's details (name, brand, items, events booked, amount paid, booking date, contact).
- The app checks the details and saves them as rows in a Google Sheet, one tab per event.
- It saves the brand logo and the payment receipt photo in a Google Drive folder owned by the organizer.

**Who uses it:** only the organizing team, behind a password. It is not a public service and has no public sign-up.
